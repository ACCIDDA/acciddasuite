# Plot surveillance data

Observed counts over time, one panel per series. When revision history
is present, the latest reported value per week is shown.

## Usage

``` r
# S3 method for class 'accidda_data'
autoplot(object, ...)
```

## Arguments

- object:

  An `accidda_data` from
  [`check_data`](https://accidda.github.io/acciddasuite/reference/check_data.md).

- ...:

  Ignored.

## Value

A ggplot object.
